📤 Как опубликовать в Telegram
@Stickers — официальный бот для создания стикеров
  • Найдите бота @Stickers в Telegram и нажмите Start
  • Отправьте команду /newpack
  • Придумайте название для вашего набора (например, "Котики программисты")
  • Загружайте стикеры по очереди: отправляйте файлы и после каждого выбирайте соответствующий эмодзи
  • После загрузки всех 10 стикеров отправьте /publish
  • Готово! Поделитесь ссылкой на набор с друзьями
✅ Все стикеры автоматически сохранены в правильном формате (512x512 PNG)
