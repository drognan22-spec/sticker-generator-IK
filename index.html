📊 Диаграмма последовательности работы системы

1
Пользователь → Генератор
Выбирает персонажа, профессию (30 вариантов), эмоции (30), стиль (15)
2
Генератор → Recraft API
Отправляет промпт + атрибуты профессии + 70% шанс юмора
3
Recraft API → Генератор
Возвращает PNG 1024x1024 → ресайз до 512x512
4
Генератор → MediaPipe (премиум)
Анализ 33 ключевых точек, определение типа объекта (человек/животное/предмет)
5
Генератор → Lottie
Создание 5-слойной анимации (голова, глаза, руки, ноги, корпус) на основе MediaPipe
6
Генератор → Пользователь
30 стикеров (21 с юмором + 9 классических) в PNG и TGS форматах
7
Генератор → localStorage
Сохранение истории генераций (до 50 записей)
